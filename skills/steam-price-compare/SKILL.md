# Steam 跨区比价工具

帮用户找到买某款 Steam 游戏的最低实际成本方案。

**实际成本 = 该区定价（转人民币）× 充值卡溢价系数**

## 工作原理

通过 Python 脚本实时查询 Steam 官方 `appdetails` API（`cc` 参数指定区域），并发获取 12 个区域的游戏定价，结合实时汇率和预设的充值卡溢价系数，计算各区的实际购买成本并排序。

**数据源：**
- **定价数据**：Steam `store.steampowered.com/api/appdetails`（官方接口，国内可直连）
- **汇率数据**：`open.er-api.com`（免费汇率 API），失败时使用兜底硬编码汇率
- **充值卡溢价**：内置参考系数（基于淘宝高销量商家 2026.04 数据）

**覆盖 12 个区域：**
中国（基准）、阿根廷、土耳其、巴西、印度、哈萨克斯坦、乌克兰、南非、哥伦比亚、美国、香港、日本

## 交互流程

1. **用户明确提到了游戏名** → 直接执行比价，输出结果
2. **用户未提到具体游戏**（如预设 query "我想买Steam游戏，帮我看看哪个区买最划算，能省多少钱"）→ 先询问用户：

> 你想查哪款游戏的跨区价格？告诉我游戏名就行，中英文都可以～

3. **用户回复了游戏名** → 直接执行比价，不要再确认

整个对话过程保持在本 Skill 内完成，不要跳出。

## 使用方式

```bash
python {SKILL_DIR}/scripts/query_steam_prices.py 游戏名称
```

游戏名称支持中英文，如：
```bash
python {SKILL_DIR}/scripts/query_steam_prices.py 黑神话悟空
python {SKILL_DIR}/scripts/query_steam_prices.py "Black Myth: Wukong"
python {SKILL_DIR}/scripts/query_steam_prices.py Elden Ring
```

脚本将格式化的纯文本比价结果输出到 stdout。

**依赖**：脚本需要 `requests` 库。如果报 `ModuleNotFoundError`，先执行 `pip install -r {SKILL_DIR}/scripts/requirements.txt`。

## 展示规则

🔴 **核心原则：脚本输出即最终展示，AI 不要自行添加额外模块。**

脚本已经输出了完整的格式化结果（标题、国区基准、比价表格、📌 说明），AI 的职责是：

1. **在脚本输出之前，加一句话结论**（告诉用户最便宜的区和能省多少）
2. **原样展示脚本输出**，不做截断、不重新排版、不额外添加内容
3. **禁止添加以下内容**：
   - ❌ "推荐方案"/"Top 3 方案" 模块
   - ❌ "跨区购买注意事项" 模块（脚本 📌 说明里已包含风险提示）
   - ❌ "区域可用性" 单独模块（脚本已在表格中标注）
   - ❌ 个性化建议段落（如"省得不多，看个人是否愿意折腾"）
   - ❌ 任何脚本输出之外的额外段落

### 一句话结论格式

放在脚本输出之前，示例：

```
🎮 《艾尔登法环》比价结论：印度区最便宜（预估 ¥222-240），比国区省 ¥58-76。如果没有跨区经验，国区 ¥298 直接买也省心。
```

**规则：**
- 提到最便宜的区 + 预估成本 + 比国区省多少
- 如果省 < ¥20，结论改为"国区已经很便宜了，不建议折腾跨区"
- 如果国区排第一，结论改为"国区已是最低价，无需跨区购买"

### 最终输出结构

```
[一句话结论]

[脚本原样输出，从"🎮 Steam 跨区比价 ——"开始到"📌 说明"结束]
```

就这些，不多不少。

## 注意事项

- Steam `appdetails` API 国内可直连，但有速率限制，并发 6 个线程已经是安全上限
- 汇率 API 偶尔超时不影响主流程（会降级使用硬编码汇率）
- 某区返回无价格信息，大概率是该区**购买锁**（不可购买），标注后展示
- 脚本报错或无输出时，告知用户"网络可能不稳定，请稍后重试"，不要编造价格数据
- 阿根廷、土耳其、美国三区虽然都是 USD，但各区定价可能不同（LATAM-USD / MENA-USD / USD 是三个不同的定价区间）
