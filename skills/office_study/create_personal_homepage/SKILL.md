# 个人主页生成

## 目标

把个人经历、能力和作品整理成可信、清晰、方便分享的个人网站。面向用户只谈个人展示效果，不要求用户准备技术资料。

## 对话方式

1. 一次最多询问 4 个问题：
   - 希望别人怎么认识你，例如摄影师、顾问、求职者或设计师？
   - 主页主要用于求职、获客、展示作品还是个人名片？
   - 有哪些简介、经历、作品、照片和链接可以使用？
   - 希望公开哪些联系方式，哪些信息不要出现？
2. 材料较乱时先帮助归类，材料较少时生成带待补提示的第一版。
3. 风格不明确时提供“专业简历”“创意作品集”“温暖个人名片”等易懂选项。

## 工作流

1. 确定个人定位、目标访问者和希望访客完成的动作。
2. 根据用途选择页面结构。默认可包含：个人介绍、擅长领域、经历、代表作品、服务方式、联系入口。
3. 把原始材料改写成自然、可信的第一人称或第三人称文案；不得增加不存在的学历、任职、客户、奖项、技能和数据。
4. 在当前任务工作区创建 `deliverables/<profile-slug>/index.html`，优先生成可直接打开的自包含静态页面。
5. 做好手机和桌面适配、作品卡片、经历时间线、联系方式和外部链接。
6. 按 `references/personal-site-checklist.md` 检查隐私、事实和分享体验。
7. 首次交付先返回可查看结果，再提供 3 个自然语言修改入口，例如“更正式”“突出作品”“隐藏手机号”。
8. 后续修改持续更新同一主页，不重复询问已确认的经历和隐私选择。

## 边界

- 默认制作展示型静态主页，不承诺会员、收费、预约后台或内容管理系统。
- 身份证号、家庭住址、私人手机号等敏感信息默认不公开；联系方式以用户明确选择为准。
- 未经用户确认不公开发布、不绑定域名、不向第三方提交个人资料。
- 用户没有主动索要时，不把源码或压缩包作为主要交付。
