# Steam 促销助手

帮用户了解当前 Steam 有哪些值得买的打折游戏，按分区推荐 + AI 推荐语。

## 使用方式

```bash
python {SKILL_DIR}/scripts/query_steam_sales.py
```

脚本将结构化 JSON 结果输出到 stdout（调试信息走 stderr）。

**依赖**：脚本需要 `requests` 库。如果报 `ModuleNotFoundError`，先执行 `pip install requests`。

## 交互流程

1. 用户触发（问 Steam 打折/促销/值得买等）→ 执行脚本
2. 拿到 JSON 输出 → 按下方格式规范展示
3. 如果脚本报错或无输出 → 告知用户"Steam 数据获取失败，可能是网络波动，请稍后再试"，**不要编造数据**

## 展示格式

### 头部

- 大促期间：显示大促名称 + 剩余天数
- 非大促期间：显示"当前为日常/周末特惠精选"

### 分区表格

每个 section 用 6 列表格展示：

```

| 游戏 | 类型 | 语言 | 折扣 | 价格 | 口碑 |
|------|------|------|------|------|------|
| **赛博朋克 2077** | 角色扮演 | 🇨🇳 简/繁 | -65% | ~~¥298~~ **¥104** | 特别好评 86.4% (93万) |

> 💬 **AI 推荐语**
> - **赛博朋克 2077**：夜之城的沉浸感无可替代，2.0 大版本后脱胎换骨。百小时打底的开放世界 RPG，这个价位入手堪称 3A 性价比天花板。

```

### 网格列表规则

1. **表格** 6 列承载硬数据：游戏名、类型、语言、折扣、价格、口碑
2. **推荐语**单独成段（AI 生成），每款游戏 1-2 句，放在表格下方
3. 语言列：有中文写"🇨🇳 简/繁"或"🇨🇳 简中"，无中文写"🌐 无中文"
4. 类型列：取 genres 主要类型，过长时只保留前 2 个
5. 口碑列格式：`review_description + positive_rate% + (total_reviews_display)`，例如"好评如潮 96.4% (12.7万)"
6. review_description 等级对照：好评如潮(≥95%且≥500条)、特别好评(≥80%且≥50条)、多半好评(≥70%)、褒贬不一(40%~69%)

### 尾部

始终附上下次大促预告：
```
---
📅 下次大促：**夏季特卖 2026**（6月25日 - 7月9日）
```

## 推荐分区逻辑

### 🔥 大作好价（5-8款）
- 筛选：评论数 ≥ 50,000 + 折扣 ≥ 50%
- 定位：知名 3A/准3A 大作
- 排序：折扣力度 > 评论数

### 💎 口碑精品（5-8款）
- 筛选：好评率 ≥ 90% + 评论数 ≥ 3,000 + 折扣 ≥ 30%
- 定位：质量极高的中小体量游戏
- 排序：好评率 > 评论数

### 🆕 新品首折（3-5款）
- 筛选：发售 ≤ 1年 + 折扣 ≥ 20%
- 定位：新游首次/大幅打折
- 排序：折扣力度 > 评论数

### 🏷️ 品类精选（追问展开）
- 用户追问"有没有好玩的 XXX 类型游戏打折"时按品类筛选
- 不默认输出

## 推荐语风格（AI 运行时生成）

**核心原则：说人话，像一个玩过这游戏的朋友在推荐**

- 第一句：这游戏是什么 / 核心体验（客观定位）
- 第二句：为什么现在值得买 / 适合谁（感性推荐）
- 禁止：套话模板（"闭眼入"、"性价比之选"）、复制官方描述、空泛赞美
- 鼓励：具体游戏体验、与同类对比、适合人群

风格示例：
- ✅ "银河恶魔城天花板，地图设计和手感都是教科书级别。打折就是入手信号，不打折也值得全价。"
- ✅ "4人联机恐怖游戏，氛围营造一绝，和朋友一起玩能笑到肚子疼。不支持中文但操作直觉化，语言门槛很低。"
- ❌ "口碑炸裂+骨折价，闭眼入不亏。"（模板感太重）
- ❌ "玩家口碑近乎完美，品质有保障。"（空泛）

**对于 AI 不熟悉的游戏**：基于 short_description + 类型 + 评价数据生成客观描述，不硬编推荐语。
